# Интерфейс диспетчера

Одна страница без прокрутки на экране от 1280 px. Слева маршруты, в центре карта Москвы, справа прогноз, сценарии, внешние факторы и качество модели. Снизу время и тепловая карта горизонта по дням и часам. На планшете и телефоне панели уходят под карту.

Стек: React 19.3, TypeScript 7.0, Vite 8.3, MapLibre GL 6.11 на векторных тайлах OpenFreeMap (OpenStreetMap), uPlot 1.6, TanStack Query 5, zustand 5. Клиент API типизирован по схеме OpenAPI сервиса (`src/api/schema.d.ts`).

## Запуск

Вместе с сервисом из корня репозитория: `docker compose up -d --build`, интерфейс на http://localhost:8080.

Для разработки нужен сервис на http://localhost:8081 (`cd backend && PORT=8081 ./gradlew bootRun`), затем:

```
cd frontend
npm ci
npm run dev            # http://localhost:5173, /api проксируется на 8081
npm run build          # проверка типов и сборка в dist/
npm run api:types      # обновить типы клиента по /api/v1/openapi
```

## Что на экране

| Блок | Что показывает | Откуда данные |
|---|---|---|
| Карта | Посадки выбранного часа: тепловая карта остановок и толщина линий. Вагоны идут с интервалом по расписанию. Объёмные дома при приближении, метро и погода по районам включаются отдельно | `/api/v1/network`, `/api/v1/network/load`, расписание transport.mos.ru, OSM, Open-Meteo |
| Время | Дата, час, «Сейчас», проигрывание со скоростью от ×1 до ×3600. Свет карты следует за солнцем над Москвой | часы симуляции в браузере |
| Маршруты | Посадки за сутки, кривая по часам, доля в сети. У выбранного маршрута интервал сейчас, посадки на рейс, ссылки на расписание и Яндекс Карты, кнопка «Пустить трамвай» | `/api/v1/network/load`, `/api/v1/factors` |
| Прогноз | Сутки по часам, месяц по дням, год по месяцам. Коридор p10-p90, пиковый период, посадки на рейс по часам | `/api/v1/forecast` или `/api/v1/forecast/scenario` |
| Сценарий | Ползунки коэффициентов модели, события (перекрытие, мероприятие, снегопад), итог по сети и по дням | `/api/v1/coefficients`, `/api/v1/forecast/scenario` |
| Факторы | Погода по часам и за горизонт, календарь, загруженность дорог, трамвай Москвы по месяцам, интервалы движения, события сети | `/api/v1/factors` |
| Модель | Скор на лидерборде, вклад факторов, бэктест, покрытие коридора, область применимости | `/api/v1/meta` |
| Тепловая карта снизу | 61 сутки × 24 часа для выбранного объекта, клик переносит время | `/api/v1/forecast` с шагом hour |

«Пустить трамвай» ведёт вагон по линии от первой до последней остановки со скоростью ×40. Камера идёт за ним, а на каждой остановке копится ожидаемая посадка за рейс: посадки маршрута в этот час × доля остановки ÷ число рейсов в час по расписанию.

Режим «Сейчас» берёт текущее время суток и такой же день недели из второй недели горизонта (10-16 ноября 2025): прогноз построен на ноябрь-декабрь 2025.

Каждый слой и эффект выключается в настройках (шестерёнка) или на панели над картой: тепловая карта, линии, остановки, трамваи, метро, объёмные дома, погода, свет по времени суток, подписи, анимации, заставка. Выбор хранится в браузере.

## Производительность

- Основной бандл 95 КБ gzip. Карта (MapLibre, 281 КБ gzip) и правая панель с uPlot (27 КБ) - отдельные чанки. Они грузятся параллельно с данными, пока идёт заставка. Вкладки «Сценарий», «Факторы», «Модель» подгружаются при первом открытии, по 2-4 КБ.
- До загрузки JS виден статичный трамвай из `index.html`, поэтому белого экрана нет.
- Посадки по 24 часам лежат в свойствах объектов карты. Смена часа меняет только выражение стиля, данные в видеокарту заново не загружаются.
- Часы симуляции обновляют состояние в каждом кадре, но компоненты подписаны на час, день или минуту, поэтому React перерисовывает их только при смене этих значений. Вагоны пересчитываются, только когда сдвинулось время.
- Соседние сутки грузятся заранее: перемотка на день вперёд или назад не ждёт сети. Ползунки отправляют запрос через 180 мс после последнего движения, повтор сценария берётся из кэша на сервере и в браузере.
- Облака рисуются шейдером в половинном разрешении и живут только до конца заставки. Осадки на карте не создают холст, пока нет осадков.
- В образе статика сжата заранее. Файлы с хэшем в имени кэшируются на год, `index.html` проверяется при каждом открытии.
