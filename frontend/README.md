# Интерфейс диспетчера

Одна страница без прокрутки на экране от 1280 px. Слева маршруты, в центре карта Москвы, справа прогноз, сценарии, внешние факторы и качество модели. Снизу время и тепловая карта по дням и часам. На планшете и телефоне панели уходят под карту, горизонтальной прокрутки нет и на 390 px.

Стек: React 19.3, TypeScript 7.0, Vite 8.3, MapLibre GL 6.11 на векторных тайлах OpenFreeMap (OpenStreetMap), uPlot 1.6, TanStack Query 5, zustand 5. Клиент API типизирован по схеме OpenAPI сервиса (`src/api/schema.d.ts`).

## Запуск

Вместе с сервисом из корня репозитория: `docker compose up -d --build`, интерфейс на http://localhost:8080 (порт меняется переменной `API_PORT`).

Для разработки нужен сервис на http://localhost:8081 (`cd backend && PORT=8081 ./gradlew bootRun`), затем:

```
cd frontend
npm ci
npm run dev            # http://localhost:5173, /api проксируется на 8081
npm run build          # проверка типов и сборка в dist/
npm run api:types      # обновить типы клиента по /api/v1/openapi
```

## Что на экране

| Блок | Что показывает | Откуда данные |
|---|---|---|
| Карта | Посадки выбранного часа: тепловая карта остановок и толщина линий. Вагоны идут с интервалом по расписанию, с приближения 15,5 они объёмные: три секции «Витязя-М», окна светятся после заката. Вид сверху или в перспективе, объёмные дома, метро | `/api/v1/network`, `/api/v1/network/load`, расписание transport.mos.ru, OSM |
| Погода на карте | Дождь и снег рисуются там, где они идут в выбранный час: сетка 5 × 5 точек по Москве, между точками значения интерполируются. Над районами подписана температура | Open-Meteo: архив для прошлых дат, прогноз на 16 дней вперёд |
| Дата и время | Любой день с 1 января 2025 по 31 октября 2026, у даты пометка источника: факт, прогноз или оценка. Проигрывание от ×1 до ×3600, «Сейчас» переносит на текущие дату и время по Москве. Свет карты и оформление следуют за солнцем | `/api/v1/calendar`, часы в браузере |
| Маршруты | Поиск остановки или маршрута, посадки за сутки, кривая по часам, доля в сети. У выбранного маршрута интервал, посадки на рейс, «Пустить трамвай», выбор участка между двумя остановками, ссылки на расписание и Яндекс Карты | `/api/v1/network/load`, `/api/v1/factors` |
| Прогноз | Сутки по часам, месяц по дням, год по месяцам для сети, маршрута, остановки или участка. Коридор, куда факт попадает в 8 случаях из 10. Посадки на рейс по часам и совет диспетчеру: в какие часы сократить интервал, чтобы на рейс приходилось не больше заданного порога посадок, и где рейсы почти пустые | `/api/v1/forecast` или `/api/v1/forecast/scenario` |
| Сценарий | Ползунки коэффициентов модели, события (перекрытие, мероприятие, снегопад), итог по сети и по дням | `/api/v1/coefficients`, `/api/v1/forecast/scenario` |
| Факторы | Погода выбранного дня по часам и за горизонт, календарь месяца, загруженность дорог, трамвай Москвы по месяцам, интервалы движения, события сети | `/api/v1/factors`, Open-Meteo |
| Модель | Точность на проверке организаторов, вклад факторов, проверка на прошлых месяцах, попадание в коридор, область применимости | `/api/v1/meta` |
| Тепловая карта снизу | 61 сутки × 24 часа от начала выбранного месяца, полоса источника под днями, клик переносит время | `/api/v1/forecast` с шагом hour |

«Пустить трамвай» ведёт вагон по линии от первой до последней остановки со скоростью ×40. Камера идёт за ним на приближении 17,4, а на каждой остановке копится ожидаемая посадка за рейс: посадки маршрута в этот час × доля остановки ÷ число рейсов в час по расписанию.

Положение карты пишется в адрес: `#map=16.3/55.7952/37.7985/-25/60` (приближение, широта, долгота, поворот, наклон). Такой ссылкой можно поделиться, облёт после заставки её не перебивает.

При первом открытии показана неделя 10-16 ноября 2025 с текущим временем суток: это горизонт прогноза из задания.

Каждый слой и эффект выключается в настройках (шестерёнка) или на панели над картой: тепловая карта, линии, остановки, трамваи, метро, объёмные дома и вагоны, погода, свет по времени суток, подписи, анимации, заставка. Выбор хранится в браузере.

## Производительность

- Основной бандл 100 КБ gzip. Карта (MapLibre, 281 КБ gzip) и правая панель с uPlot (28 КБ) - отдельные чанки. Они грузятся параллельно с данными, пока идёт заставка. Вкладки «Сценарий», «Факторы», «Модель» подгружаются при первом открытии, по 2-4 КБ.
- До загрузки JS виден статичный трамвай из `index.html`, поэтому белого экрана нет.
- Посадки по 24 часам лежат в свойствах объектов карты. Смена часа меняет только выражение стиля, данные в видеокарту заново не загружаются.
- Часы симуляции обновляют состояние в каждом кадре, но компоненты подписаны на час, день или минуту, поэтому React перерисовывает их только при смене этих значений. Вагоны пересчитываются, только когда сдвинулось время или карту сдвинули; объёмные строятся только для вагонов в кадре.
- Соседние сутки грузятся заранее: перемотка на день вперёд или назад не ждёт сети. Ползунки отправляют запрос через 180 мс после последнего движения, повтор сценария берётся из кэша на сервере и в браузере.
- Облака заставки нарисованы шейдером в мультяшном стиле (клубы с контуром, три полосы света, штриховка в тени) и живут только до конца заставки. Если видеокарта не соберёт шейдер, заставка пропускается.
- Частицы осадков проверяют погоду в своей точке раз в 6 кадров. Когда осадков нет нигде в городе, холста и кадров анимации нет.
- В образе статика сжата заранее. Файлы с хэшем в имени кэшируются на год, `index.html` проверяется при каждом открытии.
