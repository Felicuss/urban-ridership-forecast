# Час пик: интерфейс диспетчера

Одна страница без прокрутки на экране от 1280 px. Слева маршруты, рядом по кнопке выезжает панель остановок, в центре карта Москвы, справа прогноз, смена, сценарии, внешние факторы и качество модели. Снизу время и тепловая карта по дням и часам. На планшете и телефоне панели уходят под карту, горизонтальной прокрутки нет и на 390 px.

Стек: React 19.3, TypeScript 7.0, Vite 8.3, MapLibre GL 6.11 на векторных тайлах OpenFreeMap (OpenStreetMap), uPlot 1.6, TanStack Query 5, zustand 5. Клиент API типизирован по схеме OpenAPI сервиса (`src/api/schema.d.ts`).

## Запуск

Вместе с сервисом из корня репозитория: `docker compose up -d --build`, интерфейс на http://localhost:8080 (порт меняется переменной `API_PORT`).

Для разработки нужен сервис на http://localhost:8081 (`cd backend && PORT=8081 ./gradlew bootRun`), затем:

```
cd frontend
npm ci
npm run dev            # http://localhost:5173, /api проксируется на 8081
npm run build          # проверка типов и сборка в dist/
npm test               # модульные тесты расчётов диспетчера (vitest)
npm run api:types      # обновить типы клиента по /api/v1/openapi
```

## Что на экране

| Блок | Что показывает | Откуда данные |
|---|---|---|
| Карта | Посадки выбранного часа на одной шкале от синего к красному с числами в легенде: цвет и толщина линии - посадки маршрута (красный - 4000 и больше в час), кружок - посадки на остановке (красный - 160 и больше), тепловая карта складывает соседние остановки и на общем плане сливается в полосы вдоль линий. Вагоны идут с интервалом по расписанию. В перспективе они объёмные уже с приближения 11,5, раньше домов. На общем плане вагон держит 32 пикселя длины, и плоский значок, и объёмная модель. С приближения около 15,3, где настоящий вагон на экране длиннее, модель растёт вместе с картой до настоящих 34,5 м: видно окна с простенками, скошенную кабину, гармошки между секциями, тележки и токоприёмник. Вид сверху или в перспективе, объёмные дома, метро и МЦК, спутниковые снимки Esri World Imagery. Фильтр «Маршруты N/10» прячет выбранные маршруты вместе с их вагонами и остановками. Выбранный участок подсвечен | `/api/v1/network`, `/api/v1/network/load`, расписание transport.mos.ru, OSM (`analysis/s42_fetch_metro.py`) |
| Погода на карте | Дождь и снег там, где они идут в выбранный час: сетка 5 × 5 точек по Москве разворачивается в одну гладкую заливку, привязанную к карте, к краю сетки она гаснет. Частицы живут в координатах карты и едут вместе с ней при сдвиге и зуме. В легенде написано, что за осадки и где кончаются данные. Над районами подписана температура | Open-Meteo: архив для прошлых дат, прогноз на 16 дней вперёд |
| Дата и время | Любой день с 1 января 2025 по 31 декабря 2027, у даты пометка источника: факт, прогноз или оценка. Проигрывание от ×1 до ×900. «Сейчас» переносит на текущие дату и время по Москве; любой ручной выбор даты, часа или запуск времени выключает этот режим, и плашка под верхней строкой предлагает его вернуть | `/api/v1/calendar`, часы в браузере |
| Время суток | По высоте солнца над Москвой три состояния: ночь с холодным светом, сумерки с фиолетовым небом и оранжевым горизонтом, день. К закату загораются улицы (тёплое свечение, над магистралями ореол) и окна домов и вагонов, к рассвету гаснут | расчёт положения солнца в браузере, OSM |
| Маршруты | Поиск остановки или маршрута, посадки за сутки, кривая по часам, доля в сети. У выбранного маршрута интервал, посадки на рейс, «Пустить трамвай», ссылки на расписание и Яндекс Карты | `/api/v1/network/load`, `/api/v1/factors` |
| Остановки | Кнопка «Остановки и участок» в карточке маршрута открывает колонку справа от списка маршрутов, по умолчанию она скрыта. Остановки по направлениям с посадками за час, клик выбирает остановку и подлетает к ней. Внизу выбор участка между двумя остановками: прогноз, подсветка на карте, выгрузка | `/api/v1/routes/{route}/stops`, `/api/v1/network/load` |
| Прогноз | Сутки по часам, неделя и месяц по дням, год по месяцам для сети, маршрута, остановки или участка. У недели и месяца пиковый час каждого дня и список самых напряжённых дней. Коридор, куда факт попадает в 8 случаях из 10. Посадки на рейс по часам и совет диспетчеру: в какие часы сократить интервал, чтобы на рейс приходилось не больше заданного порога посадок, и где рейсы почти пустые | `/api/v1/forecast` или `/api/v1/forecast/scenario` |

Зелёным рост, красным снижение, шаги без изменений перечислены строкой. Ползунки сценария двигают полосу своего шага | `/api/v1/forecast/explain` |
| Смена | Сводка смены на выбранный день с кнопками «Скопировать для чата» и «Сводка от помощника»; оповещения на завтра по маршруту или участку с порогом посадок на рейс (колокольчик в верхней строке считает сработавшие); узкие места на 7 дней вперёд; калькулятор выпуска: интервал в вагоны на линии, посадки на рейс и вагоно-часы рядом с расписанием | `/api/v1/network/load` на неделю, расписание, Open-Meteo, `/api/v1/news` |
| Сравнение дат | Под графиком прогноза: «неделей раньше», «год назад», «через год» или любая дата. Второй ряд жёлтым пунктиром на том же графике и разница итогов | `/api/v1/forecast` |
| Сценарий | Ползунки коэффициентов модели, события (перекрытие, мероприятие, снегопад), сбои из новостей Дептранса с кнопкой «Примерить» на выбранный день, итог по сети и по дням | `/api/v1/coefficients`, `/api/v1/forecast/scenario`, `/api/v1/news` |
| Табло | Кнопка с монитором в верхней строке: полный экран для диспетчерской, крупные числа по одному маршруту (посадки в час, на рейс, интервал, следующий час, кривая суток), первым идёт маршрут, выбранный в списке, дальше маршруты сменяются каждые 8 секунд, внизу все десять, бегущая строка с оповещениями и сбоями. Пробел - пауза, стрелки - листать, Esc - выйти | `/api/v1/network/load`, расписание |

| Факторы | Погода выбранного дня по часам и за горизонт, календарь месяца, загруженность дорог, трамвай Москвы по месяцам, интервалы движения, события сети | `/api/v1/factors`, Open-Meteo |

| Тур по разделам | Открывается сам при первом входе, когда уходит заставка: 11 шагов по времени, маршрутам, карте, шкале снизу, вкладкам «Прогноз», «Сценарий», «Смена», «Факторы» и кнопкам выгрузки и табло. Повторить тур - кнопка со знаком вопроса в верхней строке | флаг `tram-ui.tour.v1` в браузере |

Клик по клетке переносит время и выделяет остановку на карте | `/api/v1/network/load` на неделю или месяц, доли остановок |

| Пропуски в данных | На вкладке «Точность»: периоды 2025 года, когда маршрут почти пропадал из данных, причина со ссылкой на пост Дептранса и восстановленные посадки. В такой день на графике прогноза восстановленные часы идут белым пунктиром рядом с фактом. Там же очистка факта: валидации вне часов работы маршрута (проверки оборудования) отброшены | `/api/v1/factors` |
| Тепловая карта снизу | 61 сутки × 24 часа от начала выбранного месяца, полоса источника под днями, клик переносит время. Если полоса снизу уже 620 px (открыта панель остановок на экране 1440 px), шкала суток занимает её целиком, а матрица возвращается, когда места хватает | `/api/v1/forecast` с шагом hour |

«Пустить трамвай» ведёт вагон по линии от первой до последней остановки со скоростью ×40. Камера идёт за ним на приближении 17,4, а на каждой остановке копится ожидаемая посадка за рейс: посадки маршрута в этот час × доля остановки ÷ число рейсов в час по расписанию.

Положение карты пишется в адрес: `#map=16.3/55.7952/37.7985/-25/60` (приближение, широта, долгота, поворот, наклон). Такой ссылкой можно поделиться, облёт после заставки её не перебивает.

При первом открытии показана неделя 10-16 ноября 2025 с текущим временем суток: это горизонт прогноза из задания.

Каждый слой и эффект выключается в настройках (шестерёнка) или на панели над картой: тепловая карта, линии, остановки, трамваи, метро, объёмные дома, спутник, погода, свет по времени суток вместе с ночными огнями, подписи, анимации, заставка. Выбор хранится в браузере.

## Производительность

- Расчёты для диспетчера (посадки на рейс, узкие места, выпуск, сводка) - чистые функции в `src/lib/dispatch.ts` и `src/lib/brief.ts` с тестами vitest. Они считают в браузере по уже загруженным кадрам прогноза, неделя вперёд - это 7 запросов, общих с картой через кэш.
- Основной бандл 100 КБ gzip. Карта (MapLibre, 281 КБ gzip) и правая панель с uPlot (28 КБ) - отдельные чанки. Они грузятся параллельно с данными, пока идёт заставка. Вкладки «Смена», «Сценарий», «Факторы», «Точность» подгружаются при первом открытии, по 2-4 КБ.
- До загрузки JS виден статичный трамвай из `index.html`, поэтому белого экрана нет.
- Посадки по 24 часам лежат в свойствах объектов карты. Смена часа меняет только выражение стиля, данные в видеокарту заново не загружаются.
- Часы симуляции обновляют состояние в каждом кадре, но компоненты подписаны на час, день или минуту, поэтому React перерисовывает их только при смене этих значений. Вагоны пересчитываются, только когда сдвинулось время или карту сдвинули; объёмные строятся только для вагонов в кадре.
- Соседние сутки грузятся заранее: перемотка на день вперёд или назад не ждёт сети. Ползунки отправляют запрос через 180 мс после последнего движения, повтор сценария берётся из кэша на сервере и в браузере.
- Заставка на SVG и CSS, без WebGL: трамвай едет на фоне сталинской высотки, а когда готовы данные и карта, за 1,4 с уезжает за край, и экран гаснет над картой. При выключенных анимациях заставка закрывается сразу.
- Объёмные вагоны строятся только для тех, что в кадре; до приближения 14 модель упрощённая, 4 слоя на секцию вместо 5 и без маски, поэтому сотня вагонов на общем плане не тормозит.
- Частицы осадков проверяют погоду в своей точке раз в 6 кадров. Когда осадков нет нигде в городе, холста и кадров анимации нет.
- В образе статика сжата заранее. Файлы с хэшем в имени кэшируются на год, `index.html` проверяется при каждом открытии.
