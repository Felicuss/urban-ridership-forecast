# Презентация «Час пик»

Презентация лежит в одном файле [`chaspik.html`](chaspik.html) весом 1,1 МБ. Шрифты, данные карты и макет сервиса вшиты внутрь, поэтому сеть и отдельные папки не нужны: файл открывается двойным кликом в Chrome или Edge.

В презентации 10 слайдов. Каждый проигрывает свою анимацию до конца и останавливается, а трамваи на улице и вагоны на карте продолжают ехать.

| Клавиша | Действие |
|---|---|
| → PgDn пробел Enter, клик | следующий слайд |
| ← PgUp, клик у левого края | предыдущий |
| Home, End | первый и последний |
| F | полный экран |

## Что на слайдах

1. Титул: карта сети, 10 маршрутов, 452 остановки, скор 0,90741.
2. Задача: утро на остановке «ВДНХ (северная)». Приходит №17, люди входят, счётчик доходит до 312 посадок на рейс при вместимости 185.
3. Прогноз: источники данных и скор v11 против 0,469 у базового решения.
4. Экран диспетчера: карта в выбранный час, ползунок времени, горизонт «год», матрица 61 × 24.
5. Маршрут: прогноз №17, остановки, сравнение дат, посадки на рейс, порог, выгрузка.
6. Вкладка «Смена»: сводка, оповещения, узкие места, калькулятор выпуска, табло.
7. Сценарии: сбой из канала Дептранса примеряется на 19 декабря.
8. Помощник: вопрос словами, агент вызывает инструменты MCP, карта летит к маршруту.
9. Польза: где и сколько часов вагоны переполнены.
10. Запуск: как устроен сервис и команда `docker compose up -d --build`.

На слайдах 4-8 вместо скриншотов нарисован макет интерфейса: курсор нажимает кнопки, камера наезжает на нужную часть экрана. Числа в макете взяты из API сервиса.

## Как устроено

Remotion Player (4.0.529) проигрывает один компонент с canvas. Каждый кадр рисуется из времени слайда, поэтому перемотка и повтор дают тот же кадр. Стиль тушью на бумаге и синьке взят из библиотеки процедурной графики проекта LCT_2026 (`src/film/lib.js`).

| Файл | Что внутри |
|---|---|
| `src/deck/slides.ts` | порядок слайдов, титул, прогноз, польза, финал |
| `src/deck/stop.ts`, `people.ts` | сцена на остановке и пассажиры |
| `src/deck/product.ts`, `layouts.ts` | сценарии курсора и раскладки слайдов с макетом |
| `src/deck/mock/` | макет интерфейса сервиса на canvas |
| `src/deck/map.ts` | карта Москвы из `city.json` |
| `src/deck/street.ts`, `landmarks.ts`, `tram.ts` | улица, силуэты Москвы, «Витязь-М» в окраске с надписью «Это автономный трамвай.» |
| `src/deck/transitions.ts`, `render.ts` | переходы между слайдами и полоса прогресса |

При загрузке, примерно за 4 секунды, заранее строятся растры карты, вагонов и все переходы. После этого кадр рисуется за 1-10 мс.

## Сборка

```bash
cd presentation
npm ci
npm run build        # tsc, vite build, копия dist/index.html в chaspik.html
```

Данные в `src/data/` уже лежат в репозитории. Чтобы пересчитать их, нужен запущенный сервис на порту 8081. Команды запускаются из корня репозитория:

```bash
uv run python presentation/scripts/build_city.py     # city.json: трассы, остановки, метро, МКАД, река
uv run python presentation/scripts/slide_facts.py    # facts.json: числа для слайдов
uv run python presentation/scripts/mock_data.py      # mock.json: данные макета интерфейса
```

`build_city.py` один раз скачивает дороги, МКАД и реку из OpenStreetMap через Overpass и кэширует их в `data/presentation_osm.json`.
