# ML: итог и передача команде

Репозиторий: [Mojarung/hakaton_moskovskogo_transporta_2026](https://github.com/Mojarung/hakaton_moskovskogo_transporta_2026), ветка `main`.
Код — `analysis/`, внешние данные — `external/`, модели и сабмиты — `forecasts/`.

**Лучшее решение — v11, скор платформы 0.90741.** Предыдущий лучший v10 —
0.90731; прирост +0.00010 при сохранении месячных сумм по маршрутам и типам дня. Скор передан пользователем, файл связан с ним по
SHA-256 в [реестре результатов](../forecasts/leaderboard_results.json).

## Что сделали

- Проверили восстановление целевой величины из сырых валидаций, аномалии и режимы движения.
- Изучили открытые решения Kaggle и реализовали адаптивные профили, LightGBM,
  дневной корректор, ансамбли и отдельную модель почасовых долей.
- Подключили календарь, фактическую погоду, городскую статистику пассажиропотока,
  запуски/восстановления маршрутов, бесплатный проезд и оперативные задержки Дептранса.
- Проверили CatBoost, ARIMA, дорожную загруженность и несколько способов
  корректировки уровня; неудачные варианты сохранены с результатами.
- Обучили плавную сезонную модель почасового профиля; её добавление к v7 подтвердило прирост на лидерборде.
- Усилили сезонный профиль и добавили дневное распределение внутри месячных групп; v11 дал ещё +0.00010.
- Зафиксировали 19 оценённых сабмитов с хешами. Траектория лучших результатов:
  **0.89950 → 0.90236 → 0.90358 → 0.90418 → 0.90553 → 0.90570 → 0.90731 → 0.90741**.

## Как устроен финал

Адаптивные почасовые профили + ансамбль LightGBM, затем коррекция дневного уровня
с весом 25%. Дополнительно две модели почасовых долей (прямая и остаточная),
их среднее подмешивается с весом 50%, сохраняя дневной объём. Мягкая поправка
по фактическому городскому трамвайному пассажиропотоку: примерно +0.98% в ноябре
и −0.29% в декабре на корректируемых маршрутах/типах дня.

Поверх v7 добавлена сезонная коррекция с весом 50%: среднее двух робастных
регрессий почасовых долей с годовыми гармониками, календарём и погодой.
Дневной ансамбль с весом 30% перераспределяет пассажиров между датами,
точно сохраняя объём каждой группы «маршрут × месяц × тип дня» от v10.
Отдельно сохранены дневные суммы 31 декабря и защищённые режимы маршрутов.

Сохранены события сети, отдельный прогноз №5, восстановленные выходные №7/50
и нулевые платные валидации 31 декабря после 20:00. Финал работает на CPU.
ARIMA с результатом 0.90309 и CatBoost в финальную смесь не входят.

Использованы разрешённые организаторами открытые данные, опубликованные после
31.10.2025. Это ретроспективный конкурсный прогноз; для сервиса на будущие даты
доступность таких факторов нужно учитывать отдельно.

## Что брать

```bash
git clone https://github.com/Mojarung/hakaton_moskovskogo_transporta_2026.git
cd hakaton_moskovskogo_transporta_2026
```

Готовый файл: [forecasts/submission_seasonal_daily_v11.csv](../forecasts/submission_seasonal_daily_v11.csv).
14 640 строк: 10 маршрутов × 61 день ноября–декабря 2025 × 24 часа.
Разделитель `;`, поля `route;date;hour;prediction`, прогнозы целые неотрицательные.
Для использования этого файла не нужны переобучение, GPU или сырые 10 ГБ валидаций.

SHA-256: `69cf0a7cf4aced43d98238fac52efb4be2c134ab08b36033f6e2f5946076e9cf`.
Метаданные и параметры — [JSON рядом](../forecasts/submission_seasonal_daily_v11.json).
Веса финальных моделей: `forecasts/kaggle_round/unified_*.txt`,
`forecasts/round4/daily_optimal.txt`, `forecasts/shape_facts_v6/*.txt`.
