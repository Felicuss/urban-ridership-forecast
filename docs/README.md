# Документация

Хакатон Московского транспорта 2026, трек «ИИ-прогноз загрузки трамвайных маршрутов». Нужно спрогнозировать почасовые посадки на 10 трамвайных маршрутах на ноябрь-декабрь 2025 по истории валидаций за январь-октябрь 2025. Качество меряют через WAPE-score.

Задание:

| Файл | Что внутри |
|---|---|
| [task.md](task.md) | Постановка: целевая величина, формат сабмита, сроки, требования к сервису, что сдавать |
| [evaluation.md](evaluation.md) | Критерии и шкала баллов, выводы для приоритизации |
| [../dataset/README.md](../dataset/README.md) | Описание датасета от организаторов: файлы, схема CSV, разбиение по датам |
| [source/task_statement.pdf](source/task_statement.pdf) | Оригинал задания (PDF) |
| [source/platform_description.txt](source/platform_description.txt) | Текст задания со страницы платформы |
