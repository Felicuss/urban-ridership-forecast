# Документация

Хакатон Московского транспорта 2026, трек «ИИ-прогноз загрузки трамвайных маршрутов». Нужно спрогнозировать почасовые посадки на 10 трамвайных маршрутах на ноябрь-декабрь 2025 по истории валидаций за январь-октябрь 2025. Качество меряют через WAPE-score.

Анализ и исследования:

[Короткий итог ML и передача команде](ml_handoff.md): финальный v6, скор 0.90553,
готовый файл, веса и граница между конкурсным прогнозом и интеграцией в сервис.

Получены скоры [шести сабмитов](../forecasts/round4/submit/README.md):
веса ансамбля, CatBoost, дневной уровень, восстановленные выходные и отдельная проверка №5.
[Результаты и воспроизведение](research/round4_2026-09-25.md).

Лучший подтверждённый скор — **0.90553**, [v6](../forecasts/submission_shape_facts_v6.csv):
почасовые доли и мягкая поправка по фактическому городскому пассажиропотоку.
Результат сообщил пользователь; прирост **+0.00135** относительно v4 (0.90418).
[Поиск фактов, отклонённые гипотезы и проверки](research/shape_facts_v6_2026-09-25.md).
[ARIMA v5](../forecasts/submission_arima_v5.csv) получила **0.90309** и отклонена
(−0.00109 к v4); [модель, результат и воспроизведение](research/arima_2026-09-25.md).
[Объединённый v4](../forecasts/submission_daily_route5_v4.csv):
дневная модель и отдельная поправка №5 затрагивают разные ячейки.
Результат платформы совпал с расчётом по аддитивности WAPE: **0.90418**.
[Кандидат v3](research/future_facts_v3_2026-09-25.md) с 0.89817 отклонён.
