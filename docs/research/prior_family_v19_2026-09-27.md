# v19: форма распределения ошибок после двух успешных итераций

[Готовый CSV](../../forecasts/submission_prior_family_v19.csv), **LB 0.91255**.
Результат сообщил пользователь: +0.00002 к v18 (0.91253). Это новый подтверждённый
рекорд; результат с SHA-256 сохранён в реестре. Следующая итерация проверяет
[совместные сценарии ошибок](joint_blocks_v20_2026-09-27.md).

## Проверенные изменения

Сначала обучена асимметрия положительных и отрицательных исторических ошибок
по маршруту, типу дня и часу (`s96_asymmetric_entropy.py`). Во всех проверенных
конфигурациях средний прирост третьей итерации оказался отрицательным. Лучший
средний результат −0.000089, худший период −0.000234. Вариант отклонён; его
CSV перенесён в локальный `data/asymmetric_entropy/rejected_ablation.csv` и
не предназначен для загрузки.

Затем проверены симметричные исходные распределения: нормальное, Student t с
тремя степенями свободы, смесь 50/50 нормального и Лапласа. Для каждого масштаб
калибруется к известной абсолютной ошибке v13; неодинаковая неопределённость ячеек,
обученная в v18, сохраняется. Постериор согласуется со всеми **30 скорами** и
**26 агрегатами**, включая новый результат 0.91253.

Выбрана смесь нормального и Лапласа, среднее постериора, вес новой оценки 1.
Это не смесь готовых CSV 50/50: смешиваются исходные распределения ошибок.

## Последовательная проверка третьего шага

В каждом периоде сначала воспроизводятся аналоги v17 и v18. После каждого
алгоритм получает только округлённый скор полученного прогноза. Третья итерация
сравнивается с лучшим уже достигнутым результатом. Периоды повторно использованы
для разработки; это имитация обратной связи, не независимый прогнозный тест.

| Период | Лучший после двух шагов | Новая оценка | Прирост |
|---|---:|---:|---:|
| R06 | 0.883921 | 0.883888 | −0.000033 |
| R08 | 0.890628 | 0.890930 | +0.000302 |
| Октябрь | 0.918547 | 0.918606 | +0.000059 |

Среднее **+0.000109**, выигрыш 2/3. Эффект небольшой, ожидаемый LB по нему не вычисляется.
Проверены веса 0.5 и 1; критерий выбора — среднее плюс половина худшего прироста.
