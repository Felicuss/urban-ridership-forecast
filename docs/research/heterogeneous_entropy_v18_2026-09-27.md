[Готовый CSV](../../forecasts/submission_heterogeneous_entropy_v18.csv), **LB 0.91253**, результат сообщил пользователь.
Новый рекорд: **+0.00030** к v17.
Основа — подтверждённый чемпион **v17, 0.91223**, улучшивший v13 на **0.00175**.

## Продолжение после нового скора

Сначала проверено простое добавление результата v17 и повторное решение той же
задачи. На истории это практически ничего не добавляло; настоящий прогноз изменился
только на 228 посадок. Этот файл **не выпущен для загрузки**, перенесён в локальный
`data/online_entropy/negligible_ablation.csv`. Скрипт s94 теперь отбрасывает такие случаи.

Следующий вариант меняет исходную неопределённость по маршруту, типу дня и часу.
Она оценивается по прошлым ошибкам v11 после удаления маршрутных месячных смещений.
Перекрывающиеся прогнозы дедуплицируются по последнему origin, будущие даты исключаются
до расчёта сумм и ошибок. Используется сглаживание малых групп и затухание старых
наблюдений. Масштаб ограничен диапазоном 0.5–2 от общего уровня.

Для настоящего теста использованы **184 исторических дня**, последняя дата 31.10.2025.
Индивидуальные ответы ноября–декабря не используются. Из них доступны только
29 скоров обычных прогнозов и 26 ранее измеренных агрегатов.

Сохраняется исходная опора распределений v13, но итоговая поправка сравнивается
с уже оценённым v17. Система согласует новые распределения со всеми 29 скорами,
включая 0.91223. Выбрано среднее распределения с полным весом нового прогноза;
оно всё ещё регуляризуется исходными распределениями.

## Проверка именно второй итерации

На каждом историческом периоде сначала воспроизводится первый шаг v17. Его
прогноз оценивается по эталону; алгоритму передаётся только округлённый скор.
Затем проверяется второй шаг с новым наблюдением и обученной на прошлом
неопределённостью. Это последовательная имитация лидерборда, не обычный forecast-CV.

Это не обещание прибавки к 0.91223. Периоды уже использовались для разработки.
