# Пробы по блокам поверх v11 и кандидат 0,90764

26.09.2026. Продолжение [проб уровня s65](level_probes_2026-09-25.md), но поверх v11
и по блокам «маршрут × месяц», особым дням и полосам часов. Скрипт
[s84_block_probes.py](../../analysis/s84_block_probes.py), файлы проб и журнал со
скорами - `forecasts/probes_v11/`, тест `tests/test_block_probes.py`.

## Как устроена проба

В пробе блока S его ячейки получают потолок H = ceil(a·v11 + b), заведомо выше факта.
Ячейки будней №17 в ноябре и декабре копируются из p11 и p12 сокомандника (потолок
1,6·v6 + 3, скоры 0,03337 и 0,03692): они держат скор пробы около 0,05-0,07, поэтому
потолок блока можно брать с запасом. Остальные ячейки нулевые. Ошибки ячеек складываются,
поэтому скор пробы s = 0,07029 + (Y_S − Σ|y − H|_S) / T, а сумма эталона по блоку
Y_S = (ΣH_S + (s − 0,07029)·T) / 2. T = 12 882 777 из p10. Пять знаков табло дают
точность около ±50 посадок на блок.

Для №50 в выходные 2-4 и 8-9 ноября (v11 считал маршрут закрытым, 2 303 посадки)
потолок взят от профиля полного выходного 15.11, чтобы не занизить сумму, если трамвай ходил.
Для №7 в те же дни нижняя граница потолка тоже от 15.11.

## Кандидат

`forecasts/submission_v11_probe_rake.csv`: v11, пересчитанный пропорционально (IPF, 300 проходов)
под 8 сумм: T, p11, p12 и пять блоков выше. Нулевые ячейки остаются нулевыми, №5 не фиксирован.
Изменено 10 258 ячеек, L1-расстояние от v11 125 490. **Скор платформы 0,90764**, лучший
подтверждённый, +0,00023 к v11. SHA-256 в [реестре](../../forecasts/leaderboard_results.json).

Прирост меньше ожидания: выигрыш от поправки уровня растёт как квадрат её ошибки, а измеренные
блоки разошлись с v11 на 0,5-5 %. По оракулам на истории знание сумм «маршрут × месяц × тип дня»
даёт около +0,01, знание каждого маршруто-дня - +0,02, но для этого нужны сотни проб.

## Воспроизведение

```bash
uv run python analysis/s84_block_probes.py build          # волна 1, q01-q23
uv run python analysis/s84_block_probes.py build pilot    # q24-q25
uv run python analysis/s84_block_probes.py build 3        # q26
uv run python analysis/s84_block_probes.py score q01 0.06115
uv run python analysis/s84_block_probes.py decode
uv run python analysis/s84_block_probes.py apply --out submission_v11_probe_rake.csv --ids q01 q02 q03 q06 q24
uv run python analysis/s84_block_probes.py apply --out submission_v11_probe_rake_r2.csv   # все пробы со скором
uv run pytest tests/test_block_probes.py
```

`build` пропускает пробы, которые уже есть в журнале, и не меняет их файлы. `apply` пишет рядом
с кандидатом JSON со списком проб и их скорами. Тест пересобирает загруженный кандидат ровно
из этих проб, поэтому новые скоры в журнале его не ломают.
Архив со всем необходимым: `forecasts/block_probes_2026-09-26.zip`.
