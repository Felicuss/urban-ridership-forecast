# Два оставшихся слота: совместная модель часовых долей

Пользователь разрешил самостоятельно распределить последние **два сабмита**. План: один слот на прошедший локальную проверку новый подход, последний — на доработку после его результата. В этой итерации **слоты не использованы и новый CSV не выпущен**: проверенная модель не показала устойчивого преимущества. Лучший подтверждённый файл по-прежнему v21, LB **0.91263**.

## Что действительно новое

Независимая регрессия часовых долей уже была в s62, сезонные профили — в s80/s85, нейросетевая совместная модель — в s67. Само разложение «уровень × профиль» новым не является.

`s118_compositional_profiles.py` реализует градиентный бустинг с групповым softmax по 24 часам. Сумма долей равна единице внутри функции потерь; градиент учитывает влияние каждого часа на нормировку остальных. Проверены кросс-энтропия и сглаженная абсолютная ошибка с положительной диагональной аппроксимацией кривизны. Базовый логарифм профиля задаётся через init_score, при прогнозе добавляется явно.

Обучающие примеры строятся с горизонтами 1/14/42/61 день. Их исходные профили используют только наблюдения до соответствующего происхождения прогноза. Все метки обучения строго раньше начала проверяемого фолда. Используются календарь, годовая гармоника, погода и часовые доли исходного профиля. Дни с плохим качеством данных исключаются по существующему флагу. Маршрут 5 и защищённые выходные 7/50 не меняются.

Сравнение проводится с лучшим историческим кандидатом после воспроизведения цепочки до v24 включительно. Это строже сравнения только с v11 или исходным v21. Для этой симуляции используются доступные исторические агрегаты и скоры, как в предыдущих экспериментах. Фолды повторно используются для разработки; независимой оценки здесь нет.

## Варианты применения

1. Прямая смесь новых долей и текущего профиля с сохранением дневных сумм.
2. `s119_profile_transfer.py`: перенос только выученной логарифмической поправки относительно причинного исходного профиля на текущий прогноз. Логарифмическая поправка ограничена ±0.35; сумма суток сохраняется.
3. `s120_winter_profiles.py`: начало обучающих целевых дат с 28-го вместо 60-го дня года. Короткие горизонты добавляют ранние зимние примеры, сохраняя требование минимум 20 дней прошлого. Это не добавление зимних меток целевого ноября–декабря.

После поправки выполняется прежнее согласование агрегатов и целочисленное округление. Сама профильная поправка сохраняет дневные суммы; последующее согласование может их изменить.

## Результаты

| Вариант | Средний прирост | Худший период |
|---|---:|---:|
| Прямая замена, smooth L1, доля 10% | −0.000087 | −0.000920 |
| Перенос поправки, smooth L1, сила 25% | +0.000235 | −0.000592 |
| Добавлена ранняя зима, перенос, smooth L1, сила 10% | +0.000137 | −0.000199 |
| Добавлена ранняя зима, перенос, smooth L1, сила 25% | +0.000193 | −0.000584 |

Ни одна проверенная конфигурация не даёт положительный прирост на всех трёх периодах. Улучшение приходится преимущественно на лето, а сентябрь–октябрь ухудшаются. Более крупные изменения усиливают провал. Дополнительные зимние примеры проблему не устранили. При двух оставшихся загрузках оснований выпускать этот вариант недостаточно.

Проверены 12 обученных моделей (2 функции потерь × 3 фолда × 2 начала обучающей истории), а также их варианты применения. Полные таблицы: `docs/analysis/tables/compositional_profiles_v25/`. Обозначение v25 в каталоге — название исследования, не готовый сабмит.

## Проверки реализации

3 теста прошли:

- градиенты обеих функций потерь совпадают с конечными разностями;
- изменение будущих целевых значений не меняет причинный исходный профиль;
- перенос поправки сохраняет суточные суммы, структурные нули и защищённые маршруты.

`git diff --check` проходит. Веса исследовательских моделей для будущего теста не обучались: локальный критерий выпуска не выполнен. Файлы v21–v24 не изменялись этим экспериментом.

Последующее решение: пользователь явно запросил два CSV несмотря на локальный риск. Выпущены обновление по обратной связи v25 и более рискованный профильный v26. [Актуальный отчёт](final_two_csv_v25_v26.md). Это не отменяет отрицательные результаты осенних проверок.
