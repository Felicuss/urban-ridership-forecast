# Один кандидат v9

Для загрузки: [submission_architecture_v9.csv](../submission_architecture_v9.csv).
**Скор платформы — 0.90543, на 0.00027 ниже v7. Лучший — v7, 0.90570.**
Вариант сохранён как оценённый эксперимент; лучшее решение не заменяет.

Финал использует почасовую форму трёх RegimeGraphNet и дневной уровень
структурной STL/ETS, затем согласует массы с оценками из проб p10–p12.
Обычный средний исторический прирост +0.003741, октябрь +0.004577.
Проверки с истинными групповыми суммами помечены `oracle_reconciled` и
не являются обычной оценкой прогнозирования.

- `graph_seed*.pt`: три обученные графовые сети, 342 667 параметров каждая.
- `graph_future.npy`, `stl_ets_future.npy`: используемые прогнозы экспертов.
- Остальные `*_future.npy`: исследованные альтернативы; **не входят в CSV**.
- `canonical_prediction.npy`: итоговые целые значения, оси дата/маршрут/час.
- `validation.csv`, `summary.csv`: сравнение отдельных моделей.
- `stack_validation.csv`: фиксированная и обучаемая смеси, отдельно обычные и oracle-проверки.
- `stack_weights.json`: **отклонённая** обучаемая смесь, сохранена для исследования.
- `fixed_route_validation.csv`: маршрутные ошибки выбранной комбинации до согласования.
- `oracle_diagnostics.csv`: диагностика при известных дневных суммах, не реальная модель.

У сырых моделей порядок маршрутов: 1, 7, 11, 12, 17, 25, 26, 28, 50.
У `canonical_prediction.npy`: 1, 5, 7, 11, 12, 17, 25, 26, 28, 50.
