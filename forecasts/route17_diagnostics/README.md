При ограниченном бюджете сначала 01–04. После получения результатов строится

Запись результатов из корня репозитория (0.03500 ниже — пример, не реальный скор):

```bash
PYTHONPATH=analysis .venv/bin/python analysis/s89_route17_probes.py score 01 0.03500
PYTHONPATH=analysis .venv/bin/python analysis/s89_route17_probes.py apply --out submission_r17_measured_v13.csv
```

Порядок, SHA-256 и параметры измерений — `ledger.json`. Известный опорный блок
у новых проб берётся из противоположного месяца, поэтому не пересекается с целью.
Если реальное значение превышает заданный потолок, декодируется заниженная сумма;
нулевой скор декодировать нельзя. Параметры не являются доказанной верхней границей.
