# Локальный нейросетевой кандидат v8

Готовый файл: [submission_joint_day_v8.csv](../submission_joint_day_v8.csv).
Скор платформы **0.90555**: −0.00015 к v7. Подтверждённый лучший — v7 = 0.90570.
Исторический выигрыш смеси не подтвердился; она не заменяет v7.

Почасовая форма: 42.25% v7, 22.75% ансамбль трёх JointDayNet, 35% pretrained
Chronos-2. Дневные суммы, закрытые часы и защищённые группы v7 сохранены.
Средний прирост на шести использованных для разработки периодах +0.001782;
все шесть положительные. Это не обещание прироста на платформе.

- `joint_day_net_seed*.pt`: три обученные на Mac сети; по 202 212 параметров.
- `future_shares.npy`: канонические доли JointDayNet, оси день/маршрут/час.
- `chronos_future.npy`: готовый прогноз Chronos, те же оси; нормируется при сборке.
- Порядок маршрутов: 1, 7, 11, 12, 17, 25, 26, 28, 50.
- `validation.csv`, `summary.csv`: проверки JointDayNet без добавления Chronos.
- `model_comparison.csv`: сравнение отдельных моделей и итоговой смеси.
- `profile_control.csv`: сравнение с историческим профилем без обучения сети.
- `run.json`: параметры и замеры 21 обучения JointDayNet.

LoRA и TiRex тестировались отдельно и не входят в данный CSV.
