## Диагностика календаря

Файлы в `diagnostics/` предназначены для измерений и имеют специально низкие
скоры. Результаты нужно привязать к точным именам файлов, а не к номерам строк
на платформе. [Манифест](diagnostics/manifest.json) содержит хеши и параметры
расшифровки. Ожидаемые скоры в манифесте — расчёт гипотезы, не результаты загрузки.

| Приоритет | Файл | Проверка |
|---|---|---|
| 1 | d01_dec29_30.csv | 29–30 декабря; это точная копия p13 из ветки коллеги |
| 2 | d02_nov01.csv | Рабочая суббота 1 ноября |
| 3 | d03_r7_50_weekends.csv | Нерабочие дни №7/50 после 15 ноября |
| 4 | d04_nov03_04.csv | Праздники 3–4 ноября |
| 5 | d05_dec31_day.csv | 31 декабря до 20:00 |

Если p13 уже был оценён, для первого пункта достаточно его результата,
повторная загрузка того же файла не нужна. v7 уже оценён; следующим нужен результат
p13; остальные пробы — очередь, а не требование загрузить все сразу.

Пробы основаны на v6, а не v7, чтобы сохранить идентичность измеренных носителей
p11/p12. Обновления по их результатам пока не включены в основной кандидат.
